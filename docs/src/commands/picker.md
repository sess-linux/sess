# Picker (interactive TUI)

```
sess
```

Running `sess` with no subcommand opens an interactive picker: every saved
session listed with its pane count, a relative size bar, and its exact
on-disk size, plus a running total at the top.

Keys:

| Key | Action |
|---|---|
| `↑` / `k`, `↓` / `j` | Move selection |
| `Enter` | Open the selected session |
| `d` | Delete the selected session |
| `q` / `Esc` | Quit |
